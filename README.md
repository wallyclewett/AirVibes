# AirVibes

Wind checker for kitesurfing, wing foiling, windsurfing and sailing.

- Current wind, gusts and direction for any spot
- Go / Marginal / No go verdict against your own limits
- Tap the compass to mark the directions that work at each spot
- Rideable daylight windows over the next 3 days, plus a 48 hour chart

Forecast data from [Open-Meteo](https://open-meteo.com) (free, no API key). Single static page, hosted on GitHub Pages. On iPhone: open in Safari, Share → Add to Home Screen.
